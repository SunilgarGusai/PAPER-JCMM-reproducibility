# PAPER022 Reproducibility Package - Mix-Design-Grouped Revision

## Environment used

- Python 3.13.5
- NumPy 2.3.5
- pandas 2.2.3
- scikit-learn 1.8.0
- Matplotlib 3.10.8

## Authoritative analysis files

- `code/paper022_analysis_v2.py` - primary 30-seed mix-design-grouped analysis.
- `code/paper022_sensitivity_v2.py` - fixed Random-Forest and support-threshold sensitivity analyses.
- `code/make_figures_v2.py` - deterministic regeneration of the four manuscript figures from saved outputs.
- `code/verify_v2_saved_results.py` - deterministic sentinel rerun against archived replicate rows.
- `data/Concrete_Data.csv` - exact analysis copy of the Yeh/UCI concrete dataset.
- `results_v2/all_replicates_v2.csv` - every primary replicate row: 30 fixed seeds for each planned scenario/method cell.
- `results_v2/submission_summary_v2.csv` - aggregated primary results used in the manuscript.
- `results_v2/model_sensitivity_random_forest_v2.csv` and `model_sensitivity_random_forest_summary_v2.csv` - fixed 10-seed model sensitivity.
- `results_v2/support_threshold_sensitivity_v2.csv` - support thresholds at the 90th, 95th, 97.5th and 99th source 1NN-distance percentiles.
- `results_v2/data_audit_v2.json` - row, exact-predictor and physical-mix counts plus source-data checksum.
- `results_v2/repetition_counts_v2.csv` - structural check of planned repetition counts.
- `logs/v2_sentinel_reproduction_audit.json` - stored-versus-regenerated numerical audit.

## Seed policy

Primary seeds are fixed as 20260901 through 20260930. Every planned scenario/method cell contains all 30 seeds. No seed was selected or removed according to its result. The Random-Forest sensitivity uses the fixed seeds 20260901 through 20260910.

## Leakage control

The evaluation unit is the exact seven-component physical mix design: cement, blast-furnace slag, fly ash, water, superplasticizer, coarse aggregate and fine aggregate. The 1,030 observations contain 427 such distinct mixes. **All curing ages of one mix remain together** across source/target splitting and model-training/conformal-calibration splitting. The 992 unique eight-predictor rows are retained only as an audit count; they are not the grouping unit in the revised study.

This grouping prevents cross-age reuse of the same physical mixture. It does not create a new finite-sample conformal theorem for clustered observations; coverage is interpreted empirically in the manuscript.

## Re-running

From the repository root:

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python code/paper022_analysis_v2.py
python code/paper022_sensitivity_v2.py
python code/make_figures_v2.py
python code/verify_v2_saved_results.py
```

A full 30-seed run is low-compute but takes longer than the sentinel audit. The sentinel verifier regenerates the strongest graded shift and the hard No-SCM holdout for seed 20260901 and compares seven headline fields for both Split-CP and Estimated-WCP with absolute tolerance `1e-12`.

## Traceability

Every manuscript headline number is an aggregation of `all_replicates_v2.csv` or one of the two declared sensitivity files. Figures are generated programmatically from machine-readable results. No scientific figure is generated by a generative-image model, and no plotted result is manually redrawn.
