# Data retrieval

The analysis uses the **Concrete Compressive Strength** dataset by I-Cheng Yeh, distributed by the UCI Machine Learning Repository.

- Dataset DOI: `10.24432/C5PK67`
- UCI licence: CC BY 4.0
- Foundational article DOI: `10.1016/S0008-8846(98)00165-3`

Download the UCI dataset and save the analysis CSV as:

`data/Concrete_Data.csv`

The expected analysis copy has 1,030 rows, eight predictors plus the compressive-strength response, no missing values, and SHA-256:

`27d7cf5170e65f866f7f1dcc8beabadfe8439efa083ad8cdd4764a6f75d8002e`

The exact analysis copy is also included in the supplementary reproducibility ZIP submitted with the manuscript. It is not duplicated in this public repository so that the canonical UCI source and its CC BY 4.0 terms remain explicit.
